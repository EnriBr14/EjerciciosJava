# Ejercicios Java

Repositorio que contiene una colección de ejercicios desarrollados en **Java** con el objetivo de practicar y reforzar conceptos fundamentales de programación.

## 📚 Descripción

Este repositorio reúne diferentes ejercicios enfocados en el aprendizaje de Java, incluyendo el uso de estructuras de control, manejo de variables, métodos y lógica de programación.

Los ejercicios están organizados para facilitar la comprensión de los conceptos básicos y mejorar las habilidades de resolución de problemas mediante programación.

## 🚀 Tecnologías utilizadas

- Java
- Programación orientada a objetos (POO)
- Lógica de programación

## 📂 Contenido del repositorio

Los ejercicios incluyen prácticas como:

- Uso de variables y tipos de datos
- Estructuras condicionales (`if`, `switch`)
- Ciclos (`for`, `while`)
- Métodos y funciones
- Resolución de problemas mediante algoritmos

## 🎯 Objetivo

El objetivo de este repositorio es:

- Practicar la sintaxis de **Java**
- Mejorar la lógica de programación
- Comprender conceptos básicos de programación orientada a objetos
- Servir como material de referencia para futuros proyectos
